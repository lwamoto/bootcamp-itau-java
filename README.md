# 🚀 Bootcamp Itaú - Java com Inteligência Artificial (DIO)

Repositório dedicado ao registro de estudos, exercícios e projetos desenvolvidos ao longo do **Bootcamp Itaú - Java com Inteligência Artificial**, promovido pela [DIO](https://www.dio.me) em parceria com o **Itaú Unibanco**.

---

## 🛠️ Tecnologias e Ferramentas

- **Linguagem:** Java 21 (LTS)
- **IDE:** IntelliJ IDEA
- **Controle de Versão:** Git & GitHub

---

## 📌 Conteúdos Estudados

- [x] Configuração de ambiente Java e IntelliJ IDEA
- [x] Sintaxe fundamental, declaração de variáveis e constantes (`final`)
- [x] Manipulação de datas com `java.time` (`LocalDate`, `Period`, `DateTimeFormatter`)
- [x] Operadores aritméticos, relacionais, lógicos e bitwise
- [x] Entrada e saída de dados com `Scanner` (`nextLine`, `nextInt`)
- [X] Estruturas de controle de fluxo
- [ ] Orientação a Objetos (POO)
- [ ] Ecossistema Spring Boot
